# 🌱 AgroTech Sustentável

## 📖 Sobre o Projeto

O AgroTech Sustentável é um site desenvolvido para o Programa Agrinho com o tema **"Agro Forte, Futuro Sustentável: equilíbrio entre produção e meio ambiente"**.

O projeto apresenta informações sobre agricultura sustentável, inovação tecnológica no campo e a importância da preservação ambiental para garantir um futuro melhor.

---

## 🎯 Objetivo

Promover a conscientização sobre a importância da sustentabilidade na agricultura, mostrando como a tecnologia pode contribuir para aumentar a produção sem causar impactos negativos ao meio ambiente.

---

## 🚜 Funcionalidades

* Página inicial informativa;
* Galeria de imagens sobre agricultura e sustentabilidade;
* Seção de vídeos educativos;
* Formulário de contato;
* Modo escuro;
* Acessibilidade com leitura em voz;
* Aumento e diminuição do tamanho da fonte;
* Integração com VLibras para tradução em Libras;
* Layout responsivo para computadores e dispositivos móveis.

---

## 💻 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* VLibras
* GitHub Pages

---

## 🌎 Tema Agrinho

O tema aborda a relação entre tecnologia, produção agrícola e preservação ambiental. O objetivo é demonstrar que é possível produzir alimentos de forma eficiente e sustentável, garantindo recursos para as futuras gerações.
